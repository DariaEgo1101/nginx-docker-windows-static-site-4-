# Сайт

Статический многостраничный сайт на HTML и CSS для интернет магазина Цвточный дом. Сайт запускается
локально в Docker с помощью веб-сервера Nginx.

## Структура проекта

``` text
nginx-static/
├── docker-compose.yml   # запуск контейнера Nginx
├── nginx.conf           # конфигурация веб-сервера
└── site/                # файлы сайта
    ├── index.html       # главная страница
    ├── другие-страницы.html
    ├── styles/          # таблицы стилей CSS
    └── image/           # изображения сайта
```

В папке `site` находятся HTML-страницы сайта, папки со стилями и
изображениями. При необходимости в этой папке могут находиться и другие
ресурсы сайта.

## Как запустить

1.  Установить и запустить Docker Desktop.

2.  Открыть терминал (например, в Visual Studio Code).

3.  Перейти в папку проекта:

    ``` powershell
    cd D:\projects\nginx-static
    ```

4.  Запустить контейнер:

    ``` powershell
    docker compose up -d
    ```

5.  Открыть сайт в браузере:

   http://127.0.0.1:8080/

Полезные команды:

``` powershell
# Проверить состояние контейнера
docker compose ps

# Посмотреть логи Nginx
docker compose logs -f

# Остановить контейнер
docker compose down
```

Файлы сайта находятся в папке `site` и подключены к контейнеру как том.
Поэтому после изменения и сохранения HTML-, CSS- или других файлов
достаточно обновить страницу в браузере --- пересобирать образ и
перезапускать контейнер не требуется.

## Страницы сайта

Укажите здесь все HTML-страницы проекта и кратко опишите назначение
каждой:

-   `index.html` --- главная страница.
-   `info.html` --- страница с информацией о доаствке.
-   `katalog.html` --- страница каталога товаров.
-   `tovar.html` --- карточка товара.
